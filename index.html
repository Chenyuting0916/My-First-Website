精選成果

減少不必要的 fallback 呼叫

修復 checksum 不一致之後，這類 fallback API 的每日呼叫量從約 75,000 次降到少於 50 次。

這是特定 fallback 的呼叫量，不是全系統錯誤率或全部 API 流量。

縮短部分 API 的回應時間

實際改善過的 API，回應時間從超過 2 秒降到約 200 毫秒。

只涵蓋這些 API，不是整個平台。沒有附上百分位數或測試條件。

擴充並修復既有測試

既有單元測試套件從 41 個增加到 240 個，並修掉原本會失敗的測試。240 是 2026-10-01 的套件總數。

用來保護既有行為、支持安全重構，不是 coverage，也不是從零新寫 240 個。
